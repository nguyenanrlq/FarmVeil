# FarmVeil

Manages crop rotation, soil quality, and irrigation schedules for small-scale farmers and gardeners.

The key benefits of using FarmVeil include:

- Manages crop rotation, soil quality,
- and irrigation schedules for small-scale
- farmers and gardeners

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/FarmVeil.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
